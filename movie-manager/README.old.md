# Movie Manager

A dynamic movie management system built with React and TypeScript that allows users to filter, search, and interact with a collection of movies.

## Features

- Add new movies with title, genre, release year, and rating
- Search movies by title
- Filter movies by genre
- Filter movies by release year range
- Sort movies by title, genre, release year, or rating
- Dark/Light mode toggle
- Responsive design for all screen sizes

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Usage

1. Add a new movie:
   - Fill in the movie details in the form at the top
   - Click "Add Movie" to add it to the collection

2. Search and Filter:
   - Use the search bar to find movies by title
   - Select a genre from the dropdown to filter by genre
   - Set the year range to filter movies by release year
   - Use the sort dropdown and order button to sort movies

3. Toggle Dark Mode:
   - Click the "Dark Mode" button in the header to switch between light and dark themes
