# Movie Manager

Movie Manager is a simple application designed to help users manage their movie collections. It allows users to add, edit, delete, and search for movies in their library.

## Features

- Add new movies with details such as title, genre, release year, and rating.
- Edit movie details.
- Delete movies from the collection.
- Search and filter movies by title, genre, or rating.
- User-friendly interface.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/movie-manager.git
    ```
2. Navigate to the project directory:
    ```bash
    cd movie-manager
    ```
3. Install dependencies:
    ```bash
    npm install
    ```

## Usage

1. Start the application:
    ```bash
    npm start
    ```
2. Open your browser and navigate to `http://localhost:3000`.

## Technologies Used

- **Frontend**: React, CSS
- **Backend**: Node.js, Express
- **Database**: MongoDB
